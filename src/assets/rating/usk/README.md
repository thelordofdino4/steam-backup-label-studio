# USK Rating Badge Assets

These SVG assets use the Wikimedia Commons USK SVG files as path-based
templates, starting from `USK_0.svg`, so the badge geometry and text placement
match the corrected vector artwork more closely than font-rendered local drafts.

The app uses these as built-in USK rating badge assets. USK can be selected as
the primary rating system, and a separate saved USK badge can be enabled as a
PEGI companion badge.

The visible text is path artwork rather than live SVG text. Wikimedia marks the
simple geometry/text as public domain, but the USK mark may still be trademarked;
confirm usage before treating these as production-ready built-in assets.
