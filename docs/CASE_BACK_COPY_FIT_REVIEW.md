# Case back copy fit review preparation

> Status: Implemented read-only source preparation for #181; not a production chooser or apply path.
> Authority: Game workflow planning/application defer to [the Game contract](GAME_SEARCH_IMPORT_AND_METADATA_WORKFLOW_CONTRACT.md); rendering and parity defer to [the SDD](SOFTWARE_DESIGN_DOCUMENT.md).

`src/caseInsert/backCoverCopyFitReview.ts` composes the existing copy generator and readability estimator. It exposes all existing Short/Medium/Full description variants, each non-empty prefix of generated feature bullets, and unchanged normalized requirements/legal candidates alongside the current target text/source. There is no selected variant. The default action is preserve, and no current text, manual source, enabled flag, layout, font size, document, session, or schema is changed.

The caller supplies target identity, current text resolved by its existing content owner, source, and layout resolved by the existing renderer/layout owner. Layout must be in the same export pixel space as preflight, not a scaled preview coordinate space. Like current export preflight, review assesses `reservedBounds` when present. Missing/nonfinite/nonpositive geometry is unavailable evidence. Empty copy is identified separately. The review stores detached immutable results and does not retain mutable input layouts.

Fit evidence is explicitly `existing-preflight-estimate`. It reuses the current average-character/line estimate and role-specific small-text/crowding warnings; it does not implement a new wrapper, decoder, font measurement, physical calibration, clipping rule, or renderer. A warning-free estimate is not visual acceptance. Rich-text styling, avoidance and actual font ink still require renderer/native validation. The review cannot authorize application and must be recreated within a fresh session/revision-bound Game plan before any future user acceptance.

Bullet prefix options preserve source order and disclose omitted counts within the generated candidate set. They let a future review show how fewer bullets affect target capacity without silently deleting content. The existing generator's five-bullet/character limits remain unchanged in this preparatory slice; complete #181 must review the candidate policy and use target space in the accepted plan. Requirements and legal text are not automatically shortened or classified as legally optional; existing density advice is retained for user review.

Production integration remains behind Game contract section 17 steps 1–5: semantic operation owners, separate discovery/application, complete immutable planning, exclusive atomic commit with lifecycle/save interlock, and the rich review adapter. #181 selection is step 6. No temporary setter path, App presentation logic, automatic medium selection, renderer change or schema extension is introduced. #149 composition and #310 paired minimal visibility retain their own owners.

Tests cover variant completeness/neutral selection, exact manual-text preservation, reduced overflow estimates for shorter variants, target-dependent bullet-prefix warnings, reserved bounds/preflight equivalence, small-font warnings without font changes, invalid/missing geometry, legal/requirements preservation, and deeply immutable detached reports. Native chooser, keyboard/focus, save/load source preservation, preview/export fit and manual-override acceptance remain pending. This preparation does not close #181.
